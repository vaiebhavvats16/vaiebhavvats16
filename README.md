## 🚀 Featured Projects

### 🎙️ [VoiceRAG — Voice-Enabled Document Q&A](VOICERAG_REPO_URL)
> **Python · FastAPI · Next.js 14 · TypeScript · Whisper · ChromaDB · Ollama**

A local-first document Q&A application — upload a PDF, ask questions by **voice or text**, and get spoken answers grounded in your document. Runs entirely on local models: no paid APIs, no data leaving the machine.

- 🎤 Hold-to-talk voice pipeline: MediaRecorder → Whisper STT → ChromaDB retrieval → llama3.2:3b (Ollama) → browser TTS
- 🧠 RAG pipeline with all-MiniLM-L6-v2 embeddings and ChromaDB semantic retrieval
- 🛡️ Context-grounded prompting + similarity filtering to reduce unsupported answers
- ⚛️ Next.js 14 TypeScript frontend integrated with a Python/FastAPI backend

[![Live Demo](https://img.shields.io/badge/Live_Demo-000?style=flat-square&logo=vercel&logoColor=white)](https://voice-rag-assistant-orcin.vercel.app/)
